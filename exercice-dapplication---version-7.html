    Dans cette configuration :

    • lignes 2-6 : les chemins de tous les fichiers JSON de l'application. La base de données utilisée est la base PostgreSQL ;
    • lignes 7-20 : les chemins de tous les fichiers PHP de l'application, sous la forme [clé => chemin]. Ce sont les fichiers de la version 5 ;
    • lignes 21-32 : les dépendances du calcul de l'impôt sous la forme d'une liste de clés du dictionnaire [dependencies] ;
    • lignes 33-40 : les dépendances du transfert en base des données du fichier JSON [taxadmindata.json], sous la même forme .

    Tous les chemins sont relatifs au dossier [version-07]. Le cours PHP 7 ajoutait à ce fichier une clé [rootDirectory] donnant le chemin absolu du dossier de la version sur la machine de l'auteur (["C:/Data/st-2019/dev/php7/poly/scripts-console/impots/version-07"]) : il fallait la modifier sur chaque nouvelle machine. Les scripts calculent désormais ce dossier eux-mêmes à partir de la constante [__DIR__]. Le dossier [php8-oct-2026] peut ainsi être placé n'importe où.

    <?php

// respect strict des types déclarés des paramètres et des résultats des fonctions
declare(strict_types=1);

// espace de noms
namespace Application;

// le dossier racine de la version 7 : les chemins du fichier de configuration sont relatifs à ce dossier
const ROOT_DIRECTORY = __DIR__ . "/..";
// chemin du fichier de configuration
const CONFIG_FILENAME = ROOT_DIRECTORY . "/Data/config.json";

// on récupère la configuration
$config = json_decode(file_get_contents(CONFIG_FILENAME), true, flags: JSON_THROW_ON_ERROR);

// on inclut les dépendances nécessaires au script
foreach ($config["dependencies4transfer"] as $dependency) {
    require_once ROOT_DIRECTORY . "/" . $config["dependencies"][$dependency];
}

// les chemins des fichiers de données
$databaseFilename = ROOT_DIRECTORY . "/" . $config["databaseFilename"];
$taxAdminDataFilename = ROOT_DIRECTORY . "/" . $config["taxAdminDataFilename"];

try {
    // création de la couche [dao]
    $dao = new DaoTransferAdminDataFromJsonFile2Database($databaseFilename, $taxAdminDataFilename);
    // transfert des données dans la base
    $dao->transferAdminData2Database();
    print "Les données de l'administration fiscale ont été transférées dans la base décrite par [{$config["databaseFilename"]}]\n";
} catch (ExceptionImpots $ex) {
    // on affiche l'erreur
    print "Erreur n° {$ex->getCode()} : {$ex->getMessage()}\n";
}
// fin
print "Terminé\n";

    Commentaires

    Le code reste celui de la version 6. La seule différence est l'exploitation du fichier [config.json] en lieu et place des constantes :

    • ligne 10 : le dossier racine de la version 7, à partir duquel sont mesurés les chemins du fichier de configuration. [__DIR__] est le dossier [Main] du script, [__DIR__ . "/.."] son dossier parent [version-07] ;
    • ligne 12 : le chemin du fichier de configuration ;
    • ligne 15 : la fonction [file_get_contents] transfère le fichier [config.json] dans une chaîne de caractères. La fonction [json_decode] exploite ensuite cette chaîne pour construire le tableau associatif [$config]. Le second paramètre [true] de la fonction [json_decode] indique qu'on veut un tableau associatif plutôt qu'un objet. Avec l'option [JSON_THROW_ON_ERROR], une erreur de syntaxe dans le fichier lance une exception [JsonException]. On ne cherche pas à gérer ici les erreurs de lecture du fichier de configuration : ce fichier fait partie de l'application, et une erreur à son niveau est une erreur de programmation que PHP signale lui-même. Les erreurs de données (fichiers JSON des données, base de données) sont, elles, toujours signalées par une [ExceptionImpots] ;
    • lignes 18-20 : on inclut les dépendances nécessaires au script de transfert :
      • [$config["dependencies4transfer"]] est le tableau des dépendances nécessaires au script de transfert. C'est une liste de clés ;
      • les chemins des fichiers à inclure sont trouvés dans le dictionnaire [$config["dependencies"]], et préfixés par le dossier racine. Par exemple, la clé [ExceptionImpots] donne le fichier [version-07/../version-05/Entities/ExceptionImpots.php] ;
      • [require_once] (et non [require] comme dans le cours PHP 7) garantit qu'un fichier n'est pas chargé deux fois, ce qui provoquerait l'erreur fatale « Cannot redeclare class … (previously declared in …) » ;
    • lignes 23-24 : les chemins complets des fichiers de données. Le cours PHP 7 les mettait dans des constantes créées par la fonction [define]. Des variables suffisent ;
    • ligne 31 : on affiche le nom du fichier décrivant la base de données utilisée. Dans une chaîne entre guillemets, l'élément de tableau [$config["databaseFilename"]] doit être entouré d'accolades .

    <?php

// respect strict des types déclarés des paramètres et des résultats des fonctions
declare(strict_types=1);

// espace de noms des tests
namespace Application\Tests;

// les classes testées
use Application\DaoImpotsWithTaxAdminDataInDatabase;
use Application\DaoTransferAdminDataFromJsonFile2Database;
use Application\TaxAdminData;
// les classes de PHPUnit
use PHPUnit\Framework\Attributes\DataProvider;
use PHPUnit\Framework\TestCase;

final class DaoTest extends TestCase
{
    // le dossier racine de la version 7
    private const string ROOT_DIRECTORY = __DIR__ . "/..";
    // la configuration de l'application
    private static array $config;

    // exécutée une fois, avant le premier test de la classe
    #[\Override]
    public static function setUpBeforeClass(): void
    {
        // on récupère la configuration
        self::$config = json_decode(file_get_contents(self::ROOT_DIRECTORY . "/Data/config.json"), true, flags: JSON_THROW_ON_ERROR);
        // on inclut les dépendances du calcul de l'impôt et celles du transfert des données
        $dependencies = array_unique([...self::$config["dependencies4calculate"], ...self::$config["dependencies4transfer"]]);
        foreach ($dependencies as $dependency) {
            require_once self::ROOT_DIRECTORY . "/" . self::$config["dependencies"][$dependency];
        }
    }

    // les deux bases de données
    public static function bases(): array
    {
        // [fichier de description de la base]
        return [
            "MySQL" => ["Data/database-mysql.json"],
            "PostgreSQL" => ["Data/database-pgsql.json"],
        ];
    }

    // les données de l'administration fiscale lues dans la base de données
    #[DataProvider("bases")]
    public function testTaxAdminData(string $databaseFilename): void
    {
        $dao = new DaoImpotsWithTaxAdminDataInDatabase(self::ROOT_DIRECTORY . "/$databaseFilename");
        $taxAdminData = $dao->getTaxAdminData();
        // constantes de calcul
        $this->assertSame(1551.0, $taxAdminData->plafondQfDemiPart);
        $this->assertSame(21037.0, $taxAdminData->plafondRevenusCelibatairePourReduction);
        $this->assertSame(42074.0, $taxAdminData->plafondRevenusCouplePourReduction);
        $this->assertSame(3797.0, $taxAdminData->valeurReducDemiPart);
        $this->assertSame(1196.0, $taxAdminData->plafondDecoteCelibataire);
        $this->assertSame(1970.0, $taxAdminData->plafondDecoteCouple);
        $this->assertSame(1595.0, $taxAdminData->plafondImpotCelibatairePourDecote);
        $this->assertSame(2627.0, $taxAdminData->plafondImpotCouplePourDecote);
        $this->assertSame(12502.0, $taxAdminData->abattementDixPourcentMax);
        $this->assertSame(437.0, $taxAdminData->abattementDixPourcentMin);
        // tranches de l'impôt
        $this->assertSame([9964.0, 27519.0, 73779.0, 156244.0, 0.0], $taxAdminData->limites);
        $this->assertSame([0.0, 0.14, 0.30, 0.41, 0.45], $taxAdminData->coeffR);
        $this->assertSame([0.0, 1394.96, 5798.0, 13913.69, 20163.45], $taxAdminData->coeffN);
    }

    // le transfert du fichier JSON vers la base, puis la relecture de la base
    #[DataProvider("bases")]
    public function testTransfert(string $databaseFilename): void
    {
        // les fichiers JSON
        $databaseFilename = self::ROOT_DIRECTORY . "/$databaseFilename";
        $taxAdminDataFilename = self::ROOT_DIRECTORY . "/" . self::$config["taxAdminDataFilename"];
        // transfert
        (new DaoTransferAdminDataFromJsonFile2Database($databaseFilename, $taxAdminDataFilename))->transferAdminData2Database();
        // relecture de la base par une couche [dao]
        $dao = new DaoImpotsWithTaxAdminDataInDatabase($databaseFilename);
        // la base contient les données du fichier JSON
        $this->assertEquals(TaxAdminData::fromJsonFile($taxAdminDataFilename), $dao->getTaxAdminData());
    }
}

    Commentaires

    • lignes 10-12 : les classes testées sont importées. L'instruction [use] ne charge pas les classes : elle permet seulement de les désigner par leur nom court ;
    • ligne 22 : la configuration de l'application, dans un attribut statique (de classe) ;
    • lignes 26-35 : la méthode statique [setUpBeforeClass] de [TestCase] est exécutée une seule fois, avant le premier test de la classe. On y lit le fichier de configuration et on charge les fichiers de l'application. Le cours PHP 7 faisait ce travail au niveau principal du fichier de test, en dehors de la classe. Avec PHPUnit, ce code est exécuté lorsque PHPUnit charge le fichier, à un moment qu'on ne maîtrise pas ; la méthode [setUpBeforeClass] est faite pour cela ;
    • ligne 31 : les tests de la couche [dao] ont besoin des dépendances du calcul de l'impôt (pour la classe [DaoImpotsWithTaxAdminDataInDatabase]) et de celles du transfert (pour la classe [DaoTransferAdminDataFromJsonFile2Database]). On réunit les deux listes, puis la fonction [array_unique] élimine les doublons ;
    • lignes 38-45 : le fournisseur de données : les fichiers de description des deux bases de données ;
    • lignes 48-49 : le test [testTaxAdminData] de la version 5 est exécuté une fois pour chacune des deux bases ;
    • lignes 71-83 : de même pour le test du transfert des données du fichier JSON vers la base de données .
