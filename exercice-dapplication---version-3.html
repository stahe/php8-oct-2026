    8. Exercice d'application – version 3

    On reprend l'exercice déjà étudié précédemment (versions 1 et 2) pour le résoudre avec un code PHP utilisant des classes. Nous allons mettre en pratique ce que nous avons appris dans les trois chapitres précédents :

    • une classe [readonly] (immuable) pour représenter les données de l'administration fiscale ;
    • une interface, une classe abstraite qui l'implémente partiellement et une classe dérivée qui la complète ;
    • un unique type d'exception, [ExceptionImpots], pour signaler toutes les erreurs de l'application ;
    • l'attribut [#[\Override]] sur toutes les méthodes qui implémentent une méthode d'interface ou redéfinissent une méthode parent .

    Commentaires

    • ligne 6 : la classe [ExceptionImpots] est dans l'espace de noms [Application]. Toutes les classes et interfaces de l'application de calcul de l'impôt seront dans cet espace de noms ;
    • ligne 9 : la classe [ExceptionImpots] étend la classe prédéfinie de PHP [RuntimeException]. Comme nous l'avons vu au chapitre sur les exceptions, une exception sert d'abord par son type : c'est lui qui permet de l'intercepter avec une clause [catch (ExceptionImpots $ex)] ;
    • lignes 11-12 : le cours PHP 7 définissait un constructeur [__construct(string $message, int $code = 0)] qui se contentait d'appeler celui de la classe parent. Il est inutile : la classe hérite du constructeur de [RuntimeException], qui accepte un message, un code d'erreur et une éventuelle exception précédente. Ce dernier paramètre nous servira à encapsuler une exception de bas niveau (une [JsonException] par exemple) dans une [ExceptionImpots] .

    <?php

declare(strict_types=1);

// espace de noms
namespace Application;

// les données de l'administration fiscale : un objet immuable
final readonly class TaxAdminData
{
    // les noms des tableaux et des constantes attendus dans les données
    private const array TABLEAUX = ["limites", "coeffR", "coeffN"];
    private const array CONSTANTES = [
        "plafondQfDemiPart",
        "plafondRevenusCelibatairePourReduction",
        "plafondRevenusCouplePourReduction",
        "valeurReducDemiPart",
        "plafondDecoteCelibataire",
        "plafondDecoteCouple",
        "plafondImpotCouplePourDecote",
        "plafondImpotCelibatairePourDecote",
        "abattementDixPourcentMax",
        "abattementDixPourcentMin",
    ];

    // constructeur privé : on passe obligatoirement par les méthodes [from...]
    private function __construct(
        // tranches d'impôt
        public array $limites,
        public array $coeffR,
        public array $coeffN,
        // constantes de calcul de l'impôt
        public float $plafondQfDemiPart,
        public float $plafondRevenusCelibatairePourReduction,
        public float $plafondRevenusCouplePourReduction,
        public float $valeurReducDemiPart,
        public float $plafondDecoteCelibataire,
        public float $plafondDecoteCouple,
        public float $plafondImpotCouplePourDecote,
        public float $plafondImpotCelibatairePourDecote,
        public float $abattementDixPourcentMax,
        public float $abattementDixPourcentMin,
    ) {
    }

    // construction à partir d'un fichier JSON
    public static function fromJsonFile(string $taxAdminDataFilename): self
    {
        // on récupère le contenu du fichier des données fiscales
        $fileContents = is_readable($taxAdminDataFilename) ? file_get_contents($taxAdminDataFilename) : false;
        // erreur ?
        if ($fileContents === false) {
            throw new ExceptionImpots("Le fichier des données [$taxAdminDataFilename] n'existe pas", 1);
        }
        // on décode le JSON dans un tableau associatif
        try {
            $data = json_decode($fileContents, true, flags: JSON_THROW_ON_ERROR);
        } catch (\JsonException $ex) {
            throw new ExceptionImpots("Le fichier de données JSON [$taxAdminDataFilename] n'a pu être exploité correctement", 2, $ex);
        }
        // le JSON doit être un objet {...}
        if (!is_array($data)) {
            throw new ExceptionImpots("Le fichier de données JSON [$taxAdminDataFilename] ne contient pas un objet JSON", 3);
        }
        // construction de l'objet à partir du tableau associatif
        return self::fromArray($data);
    }

    // construction à partir d'un tableau associatif [nom => valeur]
    public static function fromArray(array $data): self
    {
        // les clés présentes doivent être exactement celles attendues
        $attendues = [...self::TABLEAUX, ...self::CONSTANTES];
        $manquante = array_first(array_diff($attendues, array_keys($data)));
        if ($manquante !== null) {
            throw new ExceptionImpots("L'attribut [$manquante] de [TaxAdminData] n'a pas été initialisé", 4);
        }
        $inconnue = array_first(array_diff(array_keys($data), $attendues));
        if ($inconnue !== null) {
            throw new ExceptionImpots("L'attribut [$inconnue] n'existe pas dans [TaxAdminData]", 5);
        }
        // on vérifie et on convertit chaque valeur
        $valeurs = [];
        foreach (self::TABLEAUX as $clé) {
            // un tableau non vide de réels >= 0
            if (!is_array($data[$clé]) || !array_is_list($data[$clé]) || count($data[$clé]) === 0) {
                throw new ExceptionImpots("La valeur de l'attribut [$clé] est invalide", 6);
            }
            $valeurs[$clé] = array_map(fn(mixed $valeur): float => self::check($clé, $valeur), $data[$clé]);
        }
        // les trois tableaux doivent avoir la même taille
        $taille = count($valeurs["limites"]);
        if (count($valeurs["coeffR"]) !== $taille || count($valeurs["coeffN"]) !== $taille) {
            throw new ExceptionImpots("Les tableaux [limites, coeffR, coeffN] n'ont pas la même taille", 7);
        }
        foreach (self::CONSTANTES as $clé) {
            // un réel >= 0
            $valeurs[$clé] = self::check($clé, $data[$clé]);
        }
        // construction de l'objet : les clés du tableau deviennent des arguments nommés
        return new self(...$valeurs);
    }

    // vérifie qu'une valeur est un nombre réel positif ou nul et le rend sous forme de [float]
    private static function check(string $clé, mixed $value): float
    {
        // on accepte 1551, 1551.78, "1551" mais pas "xx", true, null, -3...
        if ((is_int($value) || is_float($value) || (is_string($value) && is_numeric($value)))
            && (float) $value >= 0) {
            return (float) $value;
        }
        throw new ExceptionImpots("La valeur de l'attribut [$clé] est invalide", 6);
    }

    // chaîne JSON de l'objet
    public function __toString(): string
    {
        return json_encode(get_object_vars($this), JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);
    }
}

    Commentaires

    • ligne 9 : la classe est [readonly] : tous ses attributs sont en lecture seule. Une fois construit, un objet [TaxAdminData] ne peut plus être modifié : il peut être partagé sans risque entre toutes les parties de l'application. Elle est aussi [final] : elle ne peut être dérivée ;
    • lignes 12-24 : deux constantes de classe privées rassemblent les noms des attributs attendus dans les données. Depuis PHP 8.3, une constante de classe peut être typée (ici [array]) ;
    • lignes 27-43 : le constructeur utilise la promotion des paramètres : chaque paramètre devient un attribut public de même nom et de même type. Les attributs ont les noms des clés du fichier JSON. C'est un point important qui facilite beaucoup l'écriture du code, comme nous allons le voir. Les tranches d'impôt sont des tableaux ([array]), les constantes de calcul des réels ([float]). En PHP 7, les attributs ne pouvaient pas être typés (le cours PHP 7 le regrettait) : ils le peuvent depuis PHP 7.4 ;
    • ligne 27 : le constructeur est privé : on ne peut pas écrire [new TaxAdminData(...)] en dehors de la classe. Un objet [TaxAdminData] ne peut être obtenu que par les méthodes statiques [fromJsonFile] et [fromArray], qui vérifient la validité des données. On est ainsi assuré que tout objet [TaxAdminData] contient des données valides. En PHP, une classe ne peut avoir qu'un constructeur. Les méthodes statiques qui construisent un objet, appelées parfois « constructeurs nommés », permettent d'avoir plusieurs façons de construire un objet. Le cours PHP 7 utilisait des méthodes d'instance [setFromJsonFile] appelées sur un objet vide : [(new TaxAdminData())->setFromJsonFile(...)]. C'est impossible avec un objet immuable ;
    • lignes 47-67 : la méthode [fromJsonFile] construit un objet [TaxAdminData] à partir du fichier JSON dont on lui passe le nom. Son type de retour [self] désigne la classe elle-même ;
    • lignes 50-53 : on lit le contenu du fichier. Si cela n'est pas possible, on lance une exception [ExceptionImpots]. Celle-ci remontera jusqu'au script principal ;
    • lignes 56-60 : on décode le contenu JSON du fichier. Avec l'option [JSON_THROW_ON_ERROR] (PHP 7.3), la fonction [json_decode] lance une exception [JsonException] lorsque le JSON est invalide, au lieu de rendre silencieusement [null]. On remarquera l'argument nommé [flags:] qui évite de donner une valeur au troisième paramètre [depth] de [json_decode]. L'exception [JsonException] est encapsulée dans une [ExceptionImpots] : le code appelant n'a qu'un type d'exception à gérer mais peut retrouver la cause originelle avec [$ex->getPrevious()] ;
    • lignes 62-64 : un fichier contenant par exemple le seul nombre 12 est du JSON valide : il faut vérifier qu'on a bien obtenu un tableau ;
    • ligne 66 : la suite du travail est déléguée à la méthode [fromArray]. Cette méthode est publique : elle pourra servir dans une version ultérieure où les données de l'administration fiscale viendront d'une base de données ;
    • lignes 73-81 : on vérifie que les clés du tableau [$data] sont exactement les noms attendus. [[...self::TABLEAUX, ...self::CONSTANTES]] crée un tableau contenant les éléments des deux tableaux. La fonction [array_diff] rend les éléments du premier tableau absents du second, et la fonction [array_first] (PHP 8.5) le premier élément d'un tableau ou [null] si le tableau est vide. On détecte ainsi une clé manquante puis une clé inconnue. C'est l'erreur la plus fréquente : une faute de frappe dans un nom d'attribut du fichier [taxadmindata.json]. Dans le cours PHP 7, la boucle [$this->$key = $value] créait silencieusement un attribut dynamique portant le nom erroné. Depuis PHP 8.2, la création d'attributs dynamiques est dépréciée, et elle est interdite dans une classe [readonly] ;
    • lignes 84-90 : chacun des trois tableaux doit être une liste non vide (fonction [array_is_list], PHP 8.1) dont tous les éléments sont des réels positifs ou nuls. La fonction [array_map] applique la méthode [check] à chacun des éléments ;
    • lignes 92-95 : les trois tableaux des tranches d'impôt doivent avoir la même taille ;
    • lignes 96-99 : chacune des constantes de calcul doit être un réel positif ou nul ;
    • ligne 101 : le tableau [$valeurs] a pour clés les noms des paramètres du constructeur. L'opérateur [...] appliqué à un tableau à clés chaînes transforme chaque élément en argument nommé (PHP 8.1) : cette ligne est équivalente à [new self(limites: $valeurs["limites"], coeffR: $valeurs["coeffR"], ...)]. C'est là que le choix de noms identiques pour les clés JSON et les attributs de la classe simplifie le code ;
    • lignes 105-113 : la méthode [check] vérifie qu'une valeur [$value] de type inconnu ([mixed]) est un nombre positif ou nul. Selon ce qui est écrit dans le fichier JSON, la valeur lue peut être un entier (1551), un réel (1551.78), une chaîne convertible en nombre ("1551"), une chaîne non convertible ("xx"), un booléen... La fonction [is_numeric] rend [true] pour une chaîne représentant un nombre. Le cours PHP 7 faisait cette vérification avec une expression régulière et rendait un objet [stdClass] indiquant s'il y avait eu erreur. Ici, une erreur provoque une exception et la méthode rend simplement le nombre sous la forme d'un [float] ;
    • ligne 116 : la méthode [__toString] rend la chaîne JSON des attributs de l'objet. La fonction [get_object_vars] rend un tableau associatif [nom de l'attribut => valeur] .

    8.3.1. Pourquoi n'y a-t-il plus de getters et setters ?

    Le cours PHP 7 déclarait les attributs privés et écrivait pour chacun d'eux un getter et un setter (26 méthodes), générés automatiquement par l'IDE NetBeans. Les setters étaient « fluents » : ils rendaient l'objet [$this], ce qui permettait d'enchaîner les appels [$data->setLimites($limites)->setCoeffR($coeffR)].

    Avec PHP 8, ce code n'a plus de raison d'être :

    • les getters servaient à lire des attributs privés. Les attributs [readonly] peuvent être publics sans danger puisqu'ils ne peuvent être modifiés : on écrit [$taxAdminData->plafondQfDemiPart] au lieu de [$taxAdminData->getPlafondQfDemiPart()] ;
    • les setters servaient à initialiser l'objet et permettaient de vérifier les valeurs. Un objet immuable est initialisé une fois pour toutes par son constructeur, et la vérification est faite par les méthodes [fromJsonFile] et [fromArray] ;
    • les attributs typés garantissent le type des valeurs. Le cours PHP 7 notait que l'instruction [$this->plafondQfDemiPart = 'abcd'] était possible : avec un attribut [float] et [declare(strict_types=1)], elle provoque une erreur [TypeError] .

        $test();

$taxAdminData = TaxAdminData::fromArray(["plafondQfDemiPart" => "1551"] + $valides);

    Commentaires

    • ligne 14 : construction d'un objet [TaxAdminData] valide à partir du fichier [taxadmindata.json] ;
    • ligne 15 : l'objet est inséré dans une chaîne : sa méthode [__toString] est appelée ;
    • ligne 19 : tentative de modification d'un attribut en lecture seule ;
    • ligne 25 : tentative d'utilisation du constructeur privé ;
    • ligne 31 : le tableau associatif des données valides ;
    • lignes 32-47 : un tableau de fonctions fléchées, chacune construisant un objet [TaxAdminData] à partir de données incorrectes. Les données incorrectes sont obtenues en modifiant une copie du tableau [$valides]. Avec l'opérateur [+] sur deux tableaux, ce sont les éléments du tableau de gauche qui l'emportent en cas de clé commune. La fonction [array_diff_key] rend le premier tableau privé des clés présentes dans le second ;
    • lignes 48-54 : chaque fonction est exécutée et l'exception attendue est affichée ;
    • ligne 56 : une chaîne numérique est acceptée et convertie en réel .

    public function calculerImpot(string $marié, int $enfants, int $salaire): array
    {
        // $marié : oui, non
        // $enfants : nombre d'enfants
        // $salaire : salaire annuel
        // $this->taxAdminData : données de l'administration fiscale
        //
        // on récupère les données de l'administration fiscale si ce n'est déjà fait
        $this->taxAdminData ??= $this->getTaxAdminData();
        // calcul de l'impôt avec enfants
        $result1 = $this->calculerImpot2($marié, $enfants, $salaire);
        $impot1 = $result1["impôt"];
        // calcul de l'impôt sans les enfants
        if ($enfants !== 0) {
            $result2 = $this->calculerImpot2($marié, 0, $salaire);
            $impot2 = $result2["impôt"];
            // application du plafonnement du quotient familial
            $plafondDemiPart = $this->taxAdminData->plafondQfDemiPart;
            if ($enfants < 3) {
                // plafondQfDemiPart euros pour les 2 premiers enfants
                $impot2 = $impot2 - $enfants * $plafondDemiPart;
            } else {
                // plafondQfDemiPart euros pour les 2 premiers enfants, le double pour les suivants
                $impot2 = $impot2 - 2 * $plafondDemiPart - ($enfants - 2) * 2 * $plafondDemiPart;
            }
        } else {
            $impot2 = $impot1;
            $result2 = $result1;
        }
        // on prend l'impôt le plus fort avec le taux et la surcôte qui vont avec
        if ($impot1 > $impot2) {
            $impot = $impot1;
            $taux = $result1["taux"];
            $surcôte = $result1["surcôte"];
        } else {
            $surcôte = $impot2 - $impot1 + $result2["surcôte"];
            $impot = $impot2;
            $taux = $result2["taux"];
        }
        // calcul d'une éventuelle décôte
        $décôte = $this->getDecote($marié, $salaire, $impot);
        $impot -= $décôte;
        // calcul d'une éventuelle réduction d'impôts
        $réduction = $this->getRéduction($marié, $salaire, $enfants, $impot);
        $impot -= $réduction;
        // résultat
        return [
            "impôt" => (int) floor($impot),
            "surcôte" => (int) $surcôte,
            "décôte" => (int) $décôte,
            "réduction" => (int) $réduction,
            "taux" => $taux,
        ];
    }

    private function calculerImpot2(string $marié, int $enfants, float $salaire): array
    {
        // nombre de parts
        $nbParts = match ($marié) {
            "oui" => $enfants / 2 + 2,
            "non" => $enfants / 2 + 1,
        };
        // 1 part par enfant à partir du 3e
        if ($enfants >= 3) {
            // une demi-part de + pour chaque enfant à partir du 3e
            $nbParts += 0.5 * ($enfants - 2);
        }
        // revenu imposable
        $revenuImposable = $this->getRevenuImposable($salaire);
        // surcôte
        $surcôte = floor($revenuImposable - 0.9 * $salaire);
        // pour des pbs d'arrondi
        if ($surcôte < 0) {
            $surcôte = 0;
        }
        // quotient familial
        $quotient = $revenuImposable / $nbParts;
        // les tranches d'imposition (des copies des tableaux de l'objet)
        $limites = $this->taxAdminData->limites;
        $coeffR = $this->taxAdminData->coeffR;
        $coeffN = $this->taxAdminData->coeffN;
        // est mis à la fin du tableau limites pour arrêter la boucle qui suit
        $limites[count($limites) - 1] = $quotient;
        // calcul de l'impôt
        $i = 0;
        while ($quotient > $limites[$i]) {
            $i++;
        }
        // maintenant on peut calculer l'impôt
        $impôt = floor($revenuImposable * $coeffR[$i] - $nbParts * $coeffN[$i]);
        // résultat
        return ["impôt" => $impôt, "surcôte" => $surcôte, "taux" => $coeffR[$i]];
    }

    // revenuImposable=salaireAnnuel-abattement
    // l'abattement a un min et un max
    private function getRevenuImposable(float $salaire): float
    {
        // abattement de 10% du salaire, borné par un minimum et un maximum
        $abattement = 0.1 * $salaire;
        $abattement = min($abattement, $this->taxAdminData->abattementDixPourcentMax);
        $abattement = max($abattement, $this->taxAdminData->abattementDixPourcentMin);
        // revenu imposable
        $revenuImposable = $salaire - $abattement;
        // résultat
        return floor($revenuImposable);
    }

    // calcule une décôte éventuelle
    private function getDecote(string $marié, float $salaire, float $impots): float
    {
        // au départ, une décôte nulle
        $décôte = 0;
        // montant maximal d'impôt pour avoir la décôte
        $plafondImpôtPourDécôte = $marié === "oui"
            ? $this->taxAdminData->plafondImpotCouplePourDecote
            : $this->taxAdminData->plafondImpotCelibatairePourDecote;
        if ($impots < $plafondImpôtPourDécôte) {
            // montant maximal de la décôte
            $plafondDécôte = $marié === "oui"
                ? $this->taxAdminData->plafondDecoteCouple
                : $this->taxAdminData->plafondDecoteCelibataire;
            // décôte théorique
            $décôte = $plafondDécôte - 0.75 * $impots;
            // la décôte ne peut dépasser le montant de l'impôt
            if ($décôte > $impots) {
                $décôte = $impots;
            }
            // pas de décôte < 0
            if ($décôte < 0) {
                $décôte = 0;
            }
        }
        // résultat
        return ceil($décôte);
    }

    // calcule une réduction éventuelle
    private function getRéduction(string $marié, float $salaire, int $enfants, float $impots): float
    {
        // le plafond des revenus pour avoir droit à la réduction de 20%
        $plafondRevenuPourRéduction = $marié === "oui"
            ? $this->taxAdminData->plafondRevenusCouplePourReduction
            : $this->taxAdminData->plafondRevenusCelibatairePourReduction;
        $plafondRevenuPourRéduction += $enfants * $this->taxAdminData->valeurReducDemiPart;
        if ($enfants > 2) {
            $plafondRevenuPourRéduction += ($enfants - 2) * $this->taxAdminData->valeurReducDemiPart;
        }
        // revenu imposable
        $revenuImposable = $this->getRevenuImposable($salaire);
        // réduction
        $réduction = 0;
        if ($revenuImposable < $plafondRevenuPourRéduction) {
            // réduction de 20%
            $réduction = 0.2 * $impots;
        }
        // résultat
        return ceil($réduction);
    }

    // --------------------------------------------------------------------------
    #[\Override]
    public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void
    {
        // les trois fichiers ne sont pas encore ouverts
        $errors = $results = $data = false;
        // pas mal d'erreurs peuvent se produire dès qu'on gère des fichiers
        try {
            // ouverture du fichier des erreurs
            $errors = fopen($errorsFileName, "w");
            if ($errors === false) {
                throw new ExceptionImpots("Impossible de créer le fichier des erreurs [$errorsFileName]", 10);
            }
            // ouverture du fichier des résultats
            $results = fopen($resultsFileName, "w");
            if ($results === false) {
                throw new ExceptionImpots("Impossible de créer le fichier des résultats [$resultsFileName]", 11);
            }
            // ouverture du fichier des données contribuables
            $data = is_readable($taxPayersFileName) ? fopen($taxPayersFileName, "r") : false;
            if ($data === false) {
                throw new ExceptionImpots("Impossible d'ouvrir en lecture les déclarations des contribuables [$taxPayersFileName]", 12);
            }
            // on exploite la ligne courante du fichier des données contribuables
            // qui a la forme statut marital, nombre d'enfants, salaire annuel
            $num = 0;         // n° ligne courante
            $nbErreurs = 0;   // nbre d'erreurs rencontrées
            while (($ligne = fgets($data, 100)) !== false) {
                // une ligne de plus
                $num++;
                // on enlève l'éventuelle marque de fin de ligne
                $ligne = Utilitaires::cutNewLineChar($ligne);
                // on ignore les lignes vides
                if (trim($ligne) === "") {
                    continue;
                }
                // la ligne doit avoir 3 champs marié,enfants,salaire
                $champs = array_map(trim(...), explode(",", $ligne));
                $erreur = count($champs) !== 3;
                if (!$erreur) {
                    [$marié, $enfants, $salaire] = $champs;
                    // le statut marital doit être oui ou non
                    $marié = strtolower($marié);
                    // le nombre d'enfants et le salaire doivent être des entiers positifs ou nuls
                    $erreur = !in_array($marié, ["oui", "non"], true)
                        || !preg_match('/^\d+$/', $enfants)
                        || !preg_match('/^\d+$/', $salaire);
                }
                // erreur ?
                if ($erreur) {
                    fputs($errors, "la ligne [$num] du fichier [$taxPayersFileName] est erronée\n");
                    $nbErreurs++;
                    continue;
                }
                // on calcule l'impôt
                $result = $this->calculerImpot($marié, (int) $enfants, (int) $salaire);
                // on inscrit le résultat dans le fichier des résultats
                $result = ["marié" => $marié, "enfants" => (int) $enfants, "salaire" => (int) $salaire] + $result;
                fputs($results, json_encode($result, JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR) . "\n");
            }
            // des erreurs ?
            if ($nbErreurs > 0) {
                throw new ExceptionImpots("Il y a eu $nbErreurs ligne(s) erronée(s) : voir le fichier [$errorsFileName]", 15);
            }
        } finally {
            // on ferme les fichiers qui ont été ouverts
            foreach ([$data, $results, $errors] as $fichier) {
                if ($fichier !== false) {
                    fclose($fichier);
                }
            }
        }
    }

    Commentaires du code

    • ligne 185 : la méthode reçoit trois paramètres :
      • [$taxPayersFileName] : le nom du fichier texte contenant les données des contribuables. Chaque ligne de texte contient les données d'un contribuable sous la forme : statut marital (oui / non), nombre d'enfants, salaire annuel, par exemple [oui,2,55555] ;
      • [$resultsFileName] : le nom du fichier texte qui contiendra les résultats. Chaque ligne de texte sera la chaîne JSON des résultats d'un contribuable, par exemple [{"marié":"oui","enfants":2,"salaire":50000,"impôt":1384,"surcôte":0,"décôte":384,"réduction":347,"taux":0.14}] ;

    • ligne 188 : les variables des trois fichiers sont initialisées à [false] (fichier non ouvert). Cela permettra de savoir, dans la clause [finally], quels fichiers ont été ouverts ;
    • ligne 190 : parce qu'un certain nombre d'opérations peuvent lancer une exception, une structure [try / finally] entoure tout le code de la méthode ;
    • lignes 192-204 : les trois fichiers sont ouverts. Une exception est lancée dès qu'une ouverture échoue, avec un code d'erreur différent pour chaque cas ;
    • ligne 210 : les lignes du fichier [$data] sont lues une par une à raison de 100 caractères au plus (les lignes font toutes moins de 100 caractères) ;
    • ligne 214 : on utilise la méthode statique [Utilitaires::cutNewLineChar] pour enlever l'éventuelle marque de fin de ligne ;
    • lignes 216-218 : les lignes vides (par exemple en fin de fichier) sont ignorées ;
    • ligne 220 : on découpe la ligne sur la virgule et on supprime les espaces qui entourent chaque champ. [trim(...)] est la syntaxe des « callables de première classe » (PHP 8.1) : elle désigne la fonction [trim] elle-même, sans l'appeler ;
    • ligne 221 : la ligne doit avoir exactement trois champs. Le cours PHP 7 écrivait directement [list($marié, $enfants, $salaire) = explode(",", $ligne)] : avec une ligne n'ayant que deux champs, PHP 8 émet un avertissement « Undefined array key 2 » ;
    • lignes 227-229 : la validité des trois éléments est vérifiée : le statut marital doit être oui ou non, le nombre d'enfants et le salaire doivent être des entiers positifs ou nuls (une suite de chiffres, expression régulière [/^\d+$/]). Le troisième paramètre [true] de [in_array] demande une comparaison stricte [===] ;
    • lignes 232-236 : on ne lance pas une exception si la ligne est erronée mais on écrit un message d'erreur dans le fichier texte [$errors] et on passe à la ligne suivante ;
    • ligne 238 : si la ligne lue est valide, le calcul de l'impôt est fait. On obtient un résultat sous forme de tableau associatif [impôt, surcôte, décôte, réduction, taux] ;
    • ligne 240 : au résultat obtenu, on ajoute en tête les clés [marié, enfants, salaire] ;
    • ligne 241 : le résultat est inscrit dans le fichier texte [$results] sous la forme de sa chaîne JSON. L'option [JSON_THROW_ON_ERROR] fait que la fonction [json_encode] lance une exception [JsonException] plutôt que de rendre [false] si l'encodage échoue ;
    • lignes 244-246 : à la fin de l'exploitation du fichier [$data], on regarde le nombre de lignes erronées rencontrées. S'il y en a au moins une, on lance une exception ;
    • lignes 247-254 : quelle que soit la façon dont se termine l'exécution de la méthode (normalement ou par une exception), la clause [finally] est exécutée : les fichiers qui ont été ouverts sont fermés. Le cours PHP 7 utilisait une structure [try / catch / finally] dont la clause [catch] se contentait de relancer l'exception. Elle est inutile : une structure [try / finally] sans [catch] laisse remonter l'exception après avoir exécuté la clause [finally]. Par ailleurs, le cours PHP 7 fermait les trois fichiers sans vérifier qu'ils avaient été ouverts : en PHP 8, [fclose(false)] provoque une erreur [TypeError] .

    <?php

declare(strict_types=1);

// espace de noms
namespace Application;

// une classe qui prend les données de l'administration fiscale dans un fichier JSON
class ImpotsWithTaxAdminDataInJsonFile extends AbstractBaseImpots
{
    // les données de l'administration fiscale
    private readonly TaxAdminData $taxAdminData;

    // le constructeur
    public function __construct(string $jsonFileName)
    {
        // on initialise $this->taxAdminData à partir du fichier JSON
        // peut lancer une exception ExceptionImpots
        $this->taxAdminData = TaxAdminData::fromJsonFile($jsonFileName);
    }

    // rend les données permettant le calcul de l'impôt
    #[\Override]
    public function getTaxAdminData(): TaxAdminData
    {
        return $this->taxAdminData;
    }
}

    Commentaires

    • ligne 9 : la classe [ImpotsWithTaxAdminDataInJsonFile] étend la classe abstraite [AbstractBaseImpots]. Elle doit définir la méthode [getTaxAdminData] que sa classe parent n'a pas définie ;
    • ligne 12 : l'attribut [$taxAdminData] contiendra les données de l'administration fiscale. Il est en lecture seule : il est initialisé une fois pour toutes par le constructeur. On remarquera que la classe parent a elle aussi un attribut privé [$taxAdminData] : les deux attributs sont distincts, un attribut privé n'étant visible que dans la classe qui le déclare ;
    • lignes 15-20 : le constructeur reçoit comme unique paramètre le nom du fichier JSON contenant les données fiscales ;
    • ligne 19 : un objet de type [TaxAdminData] est créé à partir du fichier JSON. Cette opération peut lancer une exception de type [ExceptionImpots]. Celle-ci remontera jusqu'au script principal [main.php] ;
    • lignes 23-27 : on donne un corps à la méthode [getTaxAdminData] que la classe parent n'avait pas définie. Ici, il suffit de rendre l'attribut [$this->taxAdminData] initialisé par le constructeur .

    8.10. Conclusion

    La version 3 a les mêmes fonctionnalités que la version 2 mais elle est mieux armée face aux erreurs : données fiscales incomplètes ou incorrectes, lignes erronées dans le fichier des contribuables, fichiers absents. Chaque erreur est signalée par une exception [ExceptionImpots] qui porte un message et un code précis.

    La classe [AbstractBaseImpots] mélange cependant deux types de code : le calcul de l'impôt d'une part, la lecture et l'écriture de fichiers d'autre part. Nous allons voir dans les chapitres suivants comment séparer ces deux préoccupations dans des couches différentes.
